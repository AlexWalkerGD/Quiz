## 📖 About the Project

**Programming Quiz** is an interactive web quiz featuring **10 multiple-choice questions** about programming concepts.  
The goal is to test your coding knowledge in a fun and engaging way, using a simple and responsive interface.

🔗 **Access the live project:** [Click here](https://alexwalkergd.github.io/Quiz/)

## ⚙️ How to Run Locally

1. Clone this repository:

    ```bash
    git clone https://github.com/alexwalkergd/Quiz.git
    ```

2. Access the project folder:

    ```bash
   cd Quiz
    ```

3. Open the `index.html` file directly in your browser  
   *(or use a VS Code extension like “Live Server” to run it locally)*
